# Project 4 – Data Visualization

## Objective
Create clear visual representations of e-commerce order data to communicate business insights.

## Dataset
- 1,200 orders
- 14 original columns
- Date range: January 2023 to June 2025
- 7 product categories
- 5 payment methods
- 5 order statuses
- 5 referral sources

## Visualizations
The Excel dashboard includes:
1. Revenue by Product
2. Monthly Revenue Trend
3. Orders by Order Status
4. Revenue by Payment Method
5. Revenue by Referral Source
6. Coupon Usage
7. KPI cards for Total Orders, Revenue, Average Order Value, Units Sold, and Unique Customers

## Key Results
- Total Orders: 1,200
- Total Revenue: $1,264,761.96
- Average Order Value: $1,053.97
- Units Sold: 3,535
- Unique Customers: 1,189
- Top Revenue Product: Chair ($195,620.11)
- Top Revenue Month: 2024-06 ($68,068.54)
- Top Referral Source by Revenue: Instagram ($275,285.45)

## Data Preparation
- Checked for missing values and duplicates.
- No duplicate orders were found.
- Missing CouponCode values were labeled `No Coupon` for visualization.
- Date fields were standardized and Year/Month fields were added for trend analysis.
