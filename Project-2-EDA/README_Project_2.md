# 📊 Project 2 — Exploratory Data Analysis (EDA)

> **Data Analytics Internship | E-Commerce Sales Analysis**

## 📌 Overview
This project performs **Exploratory Data Analysis (EDA)** on an E-Commerce dataset to discover patterns, trends, distributions, and business insights.

The analysis uses descriptive statistics and visualizations to understand sales performance, products, order status, referral sources, and order-value distribution.

## 🎯 Objectives
- Understand the dataset structure
- Calculate descriptive statistics
- Analyze monthly sales trends
- Compare product performance
- Analyze order-status distribution
- Analyze referral-source performance
- Study total-price distribution
- Identify potential outliers
- Summarize business observations

## 📈 Analysis Areas
- **Monthly Sales Trend:** identifies high- and low-performing periods.
- **Product Performance:** compares products using recorded sales, quantity, and order activity.
- **Order Status:** examines the distribution of order statuses.
- **Referral Source:** compares sales generated through referral channels.
- **Total Price Distribution:** studies typical order values and potential extreme values.

## 📌 Key Results

|---|---:|
| Total Orders | 1,200 |
| Unique Customers | 1,189 |

| Total Recorded Sales | ₹12,64,761.96 |
| Average Order Value | ₹1,053.97 |
| Median Order Value | ₹823.62 |

### Key Observations
- **Chair** recorded the highest product sales.
- **Instagram** recorded the highest sales among referral sources.
- **Credit Card** recorded the highest sales among payment methods.
- **June 2025** recorded the highest monthly sales in the analyzed period.
- Average order value is above the median, indicating relatively higher-value orders in the distribution.
- Order-status distribution should be considered before interpreting total recorded sales as net revenue.

## ⚠️ Business Note
`Total Price` is treated as **recorded order value**. Cancelled and returned orders are not automatically removed from the reported sales figure because a separate business rule for calculating **net revenue** was not provided.
