# 🧹 Project 1 — Data Cleaning & Preparation

> **Data Analytics Internship | E-Commerce Dataset**

## 📌 Overview
This project focuses on transforming a raw E-Commerce dataset into a clean, consistent, and analysis-ready dataset. The objective is to identify common data-quality issues and apply practical cleaning techniques before analysis.

## 🎯 Objectives
- Inspect and understand the raw dataset
- Identify missing / blank values
- Detect duplicate records
- Correct incorrect data formats
- Standardize text and categorical values
- Validate numerical fields
- Prepare the dataset for EDA and SQL analysis

## 🧰 Tools & Techniques
- **Microsoft Excel**
- Data validation
- Filtering & sorting
- Duplicate detection/removal
- Missing-value handling
- Text standardization
- Date and number formatting
- Data-quality checks

## 🔍 Key Cleaning Activities

### 1. Missing Values
Blank and missing values were identified and reviewed based on the relevant column and business context.

### 2. Duplicate Records
Duplicate rows were checked and removed where they represented repeated records.

### 3. Data Types & Formats
Dates, numbers, prices, quantities, and text fields were checked and standardized.

### 4. Text Consistency
Inconsistent capitalization, spacing, and categorical values were reviewed for consistency.

### 5. Validation
The final dataset was checked again for obvious quality issues before further analysis.

## 📈 Outcome
The result is a structured dataset suitable for:
- Exploratory Data Analysis
- SQL analysis
- Data visualization
- Power BI dashboards
- Business reporting

## 💡 Key Learning
This project demonstrates why **data quality is the foundation of reliable analysis**. Clean and consistent data leads to more dependable calculations, visualizations, and business insights.
